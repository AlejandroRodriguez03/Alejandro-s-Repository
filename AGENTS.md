# Instrucciones para agentes de código (Codex de ChatGPT y similares)

Este archivo lo leen automáticamente Codex de ChatGPT y otros agentes de código
al trabajar en este repositorio.

## Sobre el proyecto

- Repositorio personal de ejercicios de programación en Python.
- Todo el código está en la carpeta `EJERCICIOS/`:
  - `Ejercicios clases/`: ejercicios hechos en clase.
  - `Ejercicios prácticas/`: prácticas agrupadas por temas (`1.0 - 3.0`, `4.0 - 6.0`, `Quiz`).
  - `Ejercicios prepas/`: ejercicios de preparación.
- Cada ejercicio es un script independiente (`EJERCICIO N.py`); no hay dependencias externas.

## Cómo ejecutar

```bash
python3 "EJERCICIOS/Ejercicios prácticas/1.0 - 3.0/EJERCICIO 1.py"
```

Los nombres de carpetas y archivos tienen espacios y tildes: usa siempre comillas en las rutas.

## Convenciones

- Escribe en español: comentarios, mensajes de `print`, nombres de variables y mensajes de commit.
- Usa siempre las tildes correctamente y respeta la gramática.
- No uses rayas largas (el carácter "—"); usa comas, dos puntos o paréntesis.
- Mantén los ejercicios simples y fáciles de leer: es material de aprendizaje.
- Sigue el patrón de nombres existente (`EJERCICIO N.py`) y guarda cada ejercicio en la carpeta del tema que corresponde.
- No modifiques ni borres ejercicios existentes salvo que se pida expresamente.
